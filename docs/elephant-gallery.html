FetLife Technicolor Elephants Gallery

This gallery showcases the 7 technicolor elephant images used by the FetLife Technicolor Elephants Tampermonkey script to replace NSFW content on FetLife.com.

All images are sourced from Wikimedia Commons (public domain) or Instagram and are used under fair use for this educational/demo purpose.

The script randomly selects one of these images each time it detects and replaces NSFW content.
